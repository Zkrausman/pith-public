# Contributing to Pith

Thanks for contributing. Please open an issue before substantial work, keep changes focused, and submit all code through a pull request to `main`.

## Development

- Build: `go build -o pith.exe main.go`
- Test: `go test ./...`
- Do not commit credentials, local telemetry, generated coverage, or machine-specific agent configuration.

## Developer Certificate of Origin

By submitting a contribution, you certify that you have the right to contribute it under this repository's Apache-2.0 license and agree to the [Developer Certificate of Origin 1.1](https://developercertificate.org/). Add a `Signed-off-by: Your Name <email@example.com>` trailer to every commit (for example, `git commit -s`).
